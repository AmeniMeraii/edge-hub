# Edge Hub · Fiche produit

> Brouillon à reprendre avec tes mots. C'est ton travail de PM : garde ce qui est juste, corrige le reste.

## Problème
Les développeurs qui ont du mal à garder le fil de leur journée (concentration, perte de la notion du temps, passage d'une tâche à l'autre) perdent de l'énergie sur tout ce qui entoure le code :
- se souvenir de ce qu'ils ont fait et pourquoi, pour le daily et la réunion technique ;
- voir le temps passer, faire des pauses, s'arrêter à temps ;
- tenir leurs engagements perso (sport, pauses) quand la journée devient stressante.

Les outils existants sont dispersés (agenda, notes, minuteur, lecteur de musique) et demandent tous de changer de fenêtre, ce qui casse la concentration.

## Pour qui
- **Utilisatrice principale** : une développeuse backend en télétravail partiel, qui utilise Claude Code et Google Agenda, et qui a besoin de repères visuels permanents.
- **Utilisateurs secondaires** : tout développeur qui veut un écran d'appoint « toujours visible » pour sa concentration, avec une tablette qui dort dans un tiroir.

## Proposition de valeur
Un écran posé à côté du PC qui montre, sans rien ouvrir : sur quoi je travaille, depuis combien de temps, ce que je dois dire en réunion, et quand je dois m'arrêter pour aller courir.

## Objectifs (v1)
1. Préparer le daily et la réunion technique en moins de 2 minutes.
2. Garder une trace écrite datée de chaque tâche, sans effort.
3. Faire au moins 80 % des séances de sport prévues dans l'agenda.
4. Tout installer sur une tablette existante, sans rien acheter.

## Hors périmètre (v1)
- Températures et données matérielles avancées (décision D3).
- Appli Android native (D2).
- Synchronisation dans le cloud, multi-utilisateurs.
- Piloter Spotify via son API Web (Premium, compte développeur).

## Risques
- Le projet prend le pas sur la recherche d'emploi → limité à des créneaux fixes, et Claude Code écrit le code.
- Restrictions informatiques si le PC est celui du travail → vérifié en phase 0.
- Format des sessions Claude Code non documenté, il peut changer → lecture tolérante, uniquement des métadonnées.

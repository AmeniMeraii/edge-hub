# Roadmap

Format *Now / Next / Later* : seul le « Now » est engagé. Le reste est une intention, revue à chaque fin de phase.

## Now · v0.1 « Première version utilisable » (phases 0 à 3)
**Objectif** : la tablette affiche l'écran servi par le PC, sans dépendre de l'appli Claude.
- Socle du service, CI, dépôt public propre (phase 0)
- Stats système et lecture Spotify en console (phase 1)
- Écran actuel servi par le PC, flux temps réel (phase 2)
- Agenda Google via iCal, rappels de sport, ligne « Ensuite » (phase 3)

**Critère de sortie** : une journée de travail complète avec la tablette allumée, sans ouvrir Claude pour l'agenda.

## Next · v0.2 « Réunions et Claude Code » (phases 4 à 5)
**Objectif** : préparer les réunions et suivre Claude Code sans quitter son travail des yeux.
- Journal d'activité et page Réunions (phase 4)
- Indicateurs mesurés en local, tuile « Ma semaine » (phase 4b)
- Autorisations et notifications Claude Code sur la tablette, mascotte qui réagit (phase 4c)
- Page Musique et PC, lien focus/musique (phase 5)

**Critère de sortie** : une semaine de dailys préparés depuis la tablette.

## Later · v1.0 « Publiable » (phases 6 à 7)
- Installation automatique au démarrage, tablette en plein écran (phase 6)
- Tests avec 3 ou 4 autres devs, ajustements (phase 6b)
- README avec captures, mode démo, release, étude de cas (phase 7)

## Plus tard, peut-être (non engagé)
- API Web Spotify (aimer un morceau, choisir l'appareil)
- Thème clair, autres langues
- Version pour d'autres agendas (Outlook)
